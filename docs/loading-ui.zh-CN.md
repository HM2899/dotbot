# 页面切换与加载

首次打开页面时，侧栏和聊天区直接显示骨架屏。首次进入尚未加载的会话、例行任务、用量、模型服务商及记忆面板时，也使用对应布局的骨架屏；加载完成后显示真实内容，避免短暂显示空白或欢迎页。技能页直接使用团队状态中的已安装技能，不再等待公开目录。明暗主题和手机布局均适配，系统开启“减少动态效果”时关闭骨架动画。

最近访问的聊天在当前网页内缓存，最多保留 8 个会话、合计 2000 条消息；返回时先恢复内容和阅读位置，再后台核对历史。刷新过程中改变阅读位置，会优先保留新的位置。聊天和设置数据仅在当前页面会话的内存中缓存，重新载入网页仍从服务端读取。设置页保留切换前未提交的表单与滚动位置，缓存新鲜的页面在 15 秒内切回不会重复读取；明确保存或刷新操作仍会重新获取数据。

离开聊天时取消正在等待的历史请求，并检查请求对应的导航版本；设置页合并同一数据请求，检查当前页面及用量范围，防止较早请求的结果覆盖后来选择的页面。聊天、设置和记忆读取最多等待 15 秒，失败后显示重试入口；已有内容时继续显示内容并提示刷新失败。

侧栏和聊天列表复用未变化的节点，流式文字按浏览器绘制帧合并更新，减少整块重绘造成的闪烁，并保持未变化的附件预览、PDF iframe 和消息节点。

## 验证

```sh
cargo build
DOTBOT_CHROME=/path/to/chrome node dev/loading-ui.e2e.mjs
DOTBOT_CHROME=/path/to/chrome node dev/ui.e2e.mjs
cargo build --release && node dev/release.e2e.mjs
```

专项测试在临时团队和本地模型夹具中人为延迟或拒绝请求，检查骨架、缓存恢复、阅读位置、草稿、流式节点、预览状态、请求合并、乱序响应、失败重试和手机减少动态效果。浏览器检查复用一个浏览器、上下文和页面，并在结束时关闭测试创建的浏览器与服务。页面资源内嵌在二进制中，重新构建后需要重启正在运行的服务才能生效。
