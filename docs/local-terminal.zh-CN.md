# 本机终端协同

在 **设置 → 本机终端 → 启用本机终端协同** 打开即可使用。默认关闭，开关即时保存，下一轮对话会加载工具，无需重启服务或 Docker。可直接让 Bot 执行脚本、构建项目、查询命令输出、处理本机文件、交付附件，或把已附加的文件交给其他 Bot 协作。

“本机”是 **运行 dotbot 服务的电脑**。从手机访问服务时，命令仍在服务端执行。本功能只提供非交互式终端和文件协作，不提供本机截图、桌面控制、鼠标键盘、剪贴板或应用启动工具。Docker 桌面和独立浏览器仍属于各自原有的功能。

## 指令与目录

- `local_run`：执行 Bash 指令，返回标准输出和错误输出。默认超时 120 秒，可设置 `timeout_s` 为 1–1800 秒。每次调用都是新的 shell，`cd` 和 shell 变量不会跨调用保留；可指定现有的绝对路径 `cwd`。
- `local_status`：查看开关、暂停状态、Bash 是否可用、当前使用者及当前 Bot 的默认目录。
- `local_release`：结束本轮对本机环境的占用，让其他 Bot 接手。
- `local_send_file`：将本机绝对路径的文件附加到当前聊天。
- `local_receive_file`：将当前聊天中可见的 `media/...` 附件复制到工作目录下的 `.dotbot-inbox/<bot-id>/`，使用唯一文件名避免覆盖。

默认目录按 **群聊目录 → Bot 目录 → 团队工作目录** 选择。本机路径与 Docker 内的 `/config` 不同。指令以 dotbot 服务账户的权限运行，依赖 Linux/Unix 的 Bash 和进程组；不需要图形会话或图形输入工具。本实现不是交互式 PTY，也不维护长驻终端会话。后台子进程在指令结束时会清理，不适合启动常驻服务。

## 协作与权限

同一时间由一个会话保留本机环境，持续到它调用 `local_release` 或结束当前轮。其他 Bot 可以查看状态、协商接手或继续独立工作，不能绕过占用直接修改共享文件。交给另一 Bot 执行本机任务前应先释放占用；文件通过 `message_bot` 的附件参数分享。

开启开关不等于取消权限审批。`readonly` 仅允许查看状态和释放自身占用，不能执行 shell；`ask`、`edits` 通过用户审批，`auto` 先走自动审查，审查无法决定时再询问用户。密钥通过环境变量提供，命令输出中的已知密钥会脱敏。指令拥有服务账户的本机文件权限，因此请只批准符合任务范围的操作。

**暂停、关闭或停止对话** 会取消对应的运行中指令并终止该调用创建的进程组。暂停仍允许查询状态，恢复后可继续；关闭后后端会拒绝旧会话已加载的工具。取消不能撤销已经写入的文件。仅清理本功能启动的指令进程，不终止用户已有的终端或其他进程。

系统管理员操作遵循 Keystone 约定：先检查 `pkexec` 和 `$XDG_RUNTIME_DIR/quickshell/polkit-agent.sock`，再通过前台 `pkexec <可执行文件> <参数>` 请求系统认证。代理不可用时应报告原因；不使用 `sudo`，不在聊天中索要或向标准输入传递密码。工具审批与系统认证彼此独立。

配置保存为 `<home>/local-computer.json`，包含 `enabled`、`paused`，重启后保留；占用状态和运行进程不会恢复。代码和内置提示词修改后需重新构建，设置开关本身不需要重启。

## 验证

```sh
cargo test
cargo clippy --all-targets -- -D warnings
cargo build
node dev/local.e2e.mjs
node dev/e2e.mjs
DOTBOT_CHROME=/opt/google/chrome/chrome node dev/ui.e2e.mjs
```

集成测试在临时工作目录中执行无害命令，检查开关、审批、只读限制、密钥脱敏、目录选择、附件共享、超时、暂停、关闭和停止取消；另行检查本机图形工具与预览接口没有注册。界面测试使用一个浏览器，完成后自动关闭页面、上下文和所有测试创建的浏览器进程。

模型任务按单队列依次执行，委派附件和停止机制保留。说明见[任务与技能检查](workflows-quality-diagnostics.zh-CN.md)。本地能力仍限终端与文件，不新增图形界面操作。
